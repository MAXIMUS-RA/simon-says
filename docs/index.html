    Simon Says

    A web game built with React + TypeScript, inspired by the classic Simon Says game.

    Game Description

    The player must repeat the sequence generated by the game. With each round, the sequence becomes longer, so the difficulty increases gradually. Goal: achieve as many correct repetitions as possible without mistakes.

    Technologies

    • React
    • TypeScript
    • Vite
    • Zustand

    Requirements

    • Node.js 18+
    • npm 9+
